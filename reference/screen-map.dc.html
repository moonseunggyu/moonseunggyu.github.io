WYD에서 가져오지 않는 것

  • WYD 소개 전체 (세계청년대회란 · 상징 · 일정 · 오시는 길 · 역대 주제 · 주제가)
  • 언어 선택 모달 · GNB 언어 메뉴 (다국어는 2단계)
  • 과정 상세의 수강후기 탭 · 신청기간 · 복습기간 · 교육대상
  • 수강 현황 독립 화면 → 나의 강의실(수강 중)과 학습 이력(종료)으로 나눔
  • WYD 색 · 로고 · 사진 · 일러스트

이렇게 정해 두고 갈게요

  • 과정 상세의 총 학습시간은 목차 머리에만 표시 (예: 총 12차시 · 3시간 15분)
  • 신청 취소는 신청 내역에서. 상세 버튼은 [승인 대기중](비활성)으로만 바뀜
  • 관리자 배정 과정은 상세에서 [수강 신청] 대신 [강의실 입장]
  • 내 정보(프로필)는 마지막 지원센터 묶음과 함께 작업
  • 학습 이력 · 외부교육 · 자격은 나의 학습(마이페이지) 안에 둠
  • 공동학습 · 성장기록은 GNB 메뉴만. 화면은 아직 만들지 않음
  • 즐겨찾기는 기능 미확정이라 GNB·화면 어디에도 넣지 않음
